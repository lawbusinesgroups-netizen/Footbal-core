# Football Analytics Telegram Bot

Телеграм-бот: выбор языка → пароль → список матчей топ-лиг на 24 часа →
статистика по матчу → AI-разбор (Groq) с рекомендациями по рынкам ставок.

## Стек
- Python 3.11+, aiogram 3 (long polling)
- SQLite (aiosqlite) — сессии пользователей (язык/доступ) + кэш ответов API
- API-Football (api-sports.io, прямой ключ, бесплатный тариф — 100 запросов/день)
- TheSportsDB — резервный/дополнительный источник (без строгого лимита)
- Groq (llama-3.3-70b-versatile) — текстовый анализ статистики

## Локальный запуск
```bash
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env   # и вписать туда токены
python -m bot.main
```

## Деплой на Railway
1. Залей эту папку в GitHub-репозиторий.
2. На https://railway.app → **New Project → Deploy from GitHub repo**.
3. Railway сам подхватит `requirements.txt`. В **Variables** добавь:
   - `BOT_TOKEN`
   - `API_FOOTBALL_KEY`
   - `SPORTSDB_KEY` (можно оставить `3` — тестовый бесплатный ключ)
   - `GROQ_API_KEY`
   - `ACCESS_PASSWORD` (по умолчанию `Xaru2004`)
4. В настройках сервиса задай команду запуска (Start Command):
   `python -m bot.main`
   (Procfile тоже это укажет — `worker: python -m bot.main`).
5. Важно: это **worker**-процесс без HTTP-порта, а Railway по умолчанию ждёт
   веб-сервис. Если платформа ругается на отсутствие открытого порта —
   выбери тип сервиса **Worker** (не Web), либо на Render создай сервис типа
   **Background Worker**, а не Web Service.

## Деплой на Render
1. **New → Background Worker** (не Web Service — боту не нужен HTTP-порт).
2. Build Command: `pip install -r requirements.txt`
3. Start Command: `python -m bot.main`
4. В Environment добавь те же переменные, что и выше.

## Важные ограничения бесплатных API (честно, чтобы не было сюрпризов)
- **API-Football free**: 100 запросов/день. Поэтому список матчей и
  статистика команд кэшируются в SQLite (2–24 часа в зависимости от типа
  данных) — при активном использовании ботом несколькими людьми лимит может
  закончиться, тогда список игр не обновится до следующего дня. Решение при
  росте нагрузки — платный тариф API-Football (от ~$20/мес за 7500+ запросов).
- **Средние за последние 5 матчей** (угловые, карточки, удары, фолы,
  владение и т.д.) считаются реальным пересчётом статистики прошедших
  матчей через `/fixtures/statistics` — не выдумка и не сезонный агрегат.
  Но это дорого по квоте: 1 запрос на список последних матчей команды + до
  5 запросов на статистику каждого матча, на обе команды — то есть один
  просмотр "Статистики" впервые может стоить ~12 запросов. Чтобы не убить
  дневной лимит, статистика уже сыгранных матчей кэшируется в SQLite на
  30 дней (она не меняется), а список "последние N матчей" команды — на
  6 часов. Второй просмотр того же матча/команды почти всегда бесплатный.
- **Попадания в штангу/перекладину** — честно предупреждаю: это поле
  (`Hit Woodwork`) не гарантированно приходит от бесплатного API-Football
  для всех турниров. Код подхватит его автоматически, если API его отдаёт,
  но специально не выдумывает данные, если поля нет — тогда просто не
  показывает эту строку. Если оно принципиально важно — нужен платный
  провайдер вроде Opta/Sportmonks, где это подтверждённое поле.
- **TheSportsDB** используется как дополнение/фолбэк на случай, если по
  команде нет статистики в API-Football (не совпало название лиги/сезона
  и т.п.), либо когда дневной лимit API-Football исчерпан.

## Структура проекта
```
bot/
  main.py              # запуск бота
  config.py             # ключи, список лиг, TTL кэша
  database.py            # SQLite: пользователи + кэш
  locales.py              # тексты RU/EN
  keyboards.py             # инлайн-клавиатуры
  handlers/
    start.py               # язык + пароль
    games.py                 # список матчей
    stats.py                  # статистика по матчу
    ai_analysis.py             # Groq-анализ
  services/
    api_football.py           # клиент API-Football
    sportsdb.py                 # клиент TheSportsDB
    groq_service.py              # клиент Groq
```

## Идеи, что добавить дальше
- Push-уведомления за N минут до матча по "избранным" командам/лигам.
- Кнопка "Коэффициенты" (API-Football отдаёт и betting odds на платных
  тарифах — можно подключить отдельный бесплатный odds-провайдер).
- Фильтр списка игр по конкретной лиге (сейчас показываются все сразу).
- Мультиязычность расширить (сейчас RU/EN, локали лежат в одном файле —
  легко добавить любой язык).
- Личный кабинет / статистика по прошлым AI-рекомендациям (зашла ставка
  или нет) для самопроверки точности анализа.
